## Explicit non-findings and limits

- Approvals intentionally have no server-side expiry (`README.md:195`, `tests/test_middleware_contract.py`). This is a documented consumer contract, not a newly discovered timeout defect.
- The 20-case auth matrix confirmed foreign-tenant, revoked-key, invalid-key and missing-header requests cannot read/decide the owned approval, append its audit event, or disable its webhook. All protected state remained unchanged. Missing auth currently returns framework 422; this was recorded as observed contract, not a security bypass.
- Same idempotency key is isolated between two genuinely authenticated tenants, and same-tenant replay returns the original response.
- PostgreSQL locking, concurrent recovery redemption, replica lag, true egress restrictions, and provider behavior were not dynamically tested. SQLite results do not prove PostgreSQL concurrency safety.
- Administrator purge child-record foreign-key behavior was a source-review candidate only and was not added to confirmed counts. The sweep avoids exercising delete operations against real data.
- Known placeholder defaults and runtime-generated synthetic keys are not treated as exposure of real credentials. No real secret exposure was identified in this pass.
